# Arbeitsrealität Analyse

Kurze interaktive Umfrage zur Analyse von Arbeitsrealität, Wechselgedanken und Selbständigkeit.

## Live Demo
https://learnolane.github.io/umfrage/

## Features
- Branch-basierte Fragenlogik
- Automatische Auswertung
- Speicherung via Google Sheets

## Zweck
Erkennen von Mustern in:
- Arbeitszufriedenheit
- Wechselmotivation
- Selbständigkeitsinteresse
